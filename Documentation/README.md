# Documentation

Detail pages for [Jorvik Daily News](../README.md). The README says what the app is; these say how it works and why it works that way.

Much of this is a record of things that were wrong first. Where a number appears — a threshold, a cap, a timing — it was measured rather than chosen, and the measurement is given so you can disagree with the conclusion.

## Using it

- **[Using it](using-it.md)** — adding feeds, import and export, pausing a source, and everything the reader pane does.
- **[Troubleshooting](troubleshooting.md)** — an empty paper, an article that will not open, a missing picture, and the diagnostics that tell you which you have.

## How it works

- **[How the paper is built](the-paper.md)** — today-only publishing, how the front page picks its lead, and how a standfirst is fitted to the space each card actually has.
- **[Pictures](pictures.md)** — where a picture comes from when a feed supplies none, how one is cropped around its subject, and what the memory accounting really measures.
- **[Video, PDFs and awkward pages](media.md)** — what happens when an item is not an article.
- **[Storage](storage.md)** — what is kept, where, and what deliberately is not.

## Under the bonnet

- **[Architecture](architecture.md)** — the extraction ladder, the parsers, and the platform self-test.
- **[Handling hostile content](security.md)** — the threat model, and what a review of the whole surface found.
- **[Building from source](building.md)** — the build, the test suite, and how updates are delivered.
